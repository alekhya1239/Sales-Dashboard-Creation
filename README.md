📊 Sales & Dashboard Creation Using Microsoft Excel

📌 Project Overview

This project focuses on analyzing sales data and creating an interactive Sales Dashboard using Microsoft Excel. The dashboard provides a clear view of sales performance through key metrics, charts, and visualizations.

The project demonstrates practical skills in Excel data cleaning, data analysis, Pivot Tables, formulas, charts, and dashboard creation.

🎯 Objectives

- Analyze sales and product performance.
- Clean and organize raw sales data.
- Identify top-performing products and categories.
- Analyze sales trends and performance.
- Create an interactive and easy-to-understand dashboard.
- Present important business insights using Excel visualizations.

🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Charts & Visualizations
- Dashboard Design
- Conditional Formatting
- KPI Analysis

📂 Project Workflow

1. Data Collection

Imported the sales dataset into Microsoft Excel and reviewed the available columns and records.

2. Data Cleaning

- Checked for missing and duplicate values.
- Corrected inconsistent data.
- Organized columns and data formats.
- Prepared the dataset for analysis.

3. Data Analysis

Used Excel formulas and Pivot Tables to analyze:

- Total Sales
- Product Performance
- Category-wise Sales
- Sales Trends
- Top Products
- Overall Sales Performance

4. Dashboard Creation

Created an interactive dashboard containing:

- 📈 Sales trend charts
- 📊 Product/category analysis
- 💰 Sales KPIs
- 📋 Summary tables
- 📉 Interactive visualizations

5. Insights

The dashboard helps identify sales patterns, high-performing products, and areas that require further attention.

📊 Dashboard Features

The Excel dashboard provides a summarized view of sales performance and allows users to understand the data quickly through visual charts and KPIs.

Key components include:

- Total Sales KPI
- Product-wise Sales
- Category-wise Sales
- Sales Trend Analysis
- Top-performing Products
- Interactive Pivot Charts
